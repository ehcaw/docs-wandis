# Getting started

1. Install the Mintlify CLI with `npm i -g mint`.
2. Run `mint dev` from the repository root to preview the docs at `http://localhost:3000`.
3. Run `mint broken-links` before you push to catch broken links.
4. Push to `main` to deploy.
